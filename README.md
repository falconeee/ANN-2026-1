## 📘 Assignment 1

### Part 1 — Gradient descent (`T1/T1_pt1.ipynb`)

From-scratch implementation of **gradient descent**, the basis of neural network training.

| Question | What is done |
|---|---|
| **Q1** | One gradient descent step on $f(x) = e^{-x}\,x(x^2 - x - 1)$ from $x_0 = 1$, approximating the derivative with **finite differences** ($h = 0.01$, $\alpha = 0.1$). |
| **Q2** | The same step, now with the **analytical derivative** obtained via `sympy.diff` + `lambdify`, compared with the numerical approximation. |
| **Q3** | Full gradient descent from $x_0 = 3$, with stopping criteria $\lvert f'(x)\rvert < g_{\min} = 0.1$ and $k_{\max} = 100$. Plots the trajectory $x_k \to f(x_k)$ over the curve. |
| **Q4** | Search for **two local minima** of a two-dimensional function (a variant of the *six-hump camel*), using (a) a finite-difference gradient, (b) an explicit gradient and (c) a visualization of the trajectory on 2D contour lines and a 3D surface. |

**Main results**

- Q1 → $x_1 \approx 0.96266$ (approximate gradient $\approx 0.37337$)
- Q2 → $x_1 \approx 0.96321$ (exact gradient $= 1/e \approx 0.36788$)
- Q3 → minimum at $x \approx 0.78494$, $f(x) \approx -0.41849$, after 49 iterations
- Q4 → different minima depending on the starting point, showing that for non-convex functions the result depends on the initialization

### Part 2 — Fault detection in a chemical reactor (`T1/T1_pt2.ipynb`)

Application of a **linear classifier trained by gradient descent** to a real engineering problem: diagnosing faults in a **CSTR** (*Continuous Stirred-Tank Reactor*).

The data is generated by the [CSTRSIM](https://github.com/twrauber/CSTRSIM) simulator, which models the reactor in closed loop (controllers, sensors and safety limits).

**Notebook pipeline**

1. **Simulation** — 5 scenarios of 500 min each; in the faulty scenarios, the fault is triggered at minute 200:

   | Class | Fault |
   |---|---|
   | `normal` | Normal operation |
   | `2` | Blockage at the reactor outlet |
   | `3` | Blockage in the cooling jacket |
   | `12` | Abnormal feed flow |
   | `17` | Abnormal pressure at the jacket outlet |

2. **Consolidation** — the CSVs are merged into a single dataset of **2505 samples × 18 attributes** (14 measured variables + 4 physical constraints).
3. **Exploratory analysis** — class distribution (imbalanced dataset: `normal` ≈ 52%), missing-value check and descriptive statistics.
4. **Preprocessing** — label encoding, stratified **60% train / 20% validation / 20% test** split and standardization with `StandardScaler` (fit on the training set only, avoiding *data leakage*).
5. **Model** — **Softmax Regression** implemented by hand with NumPy: cross-entropy + L2 regularization, optimized by mini-batch SGD (η = 0.1, 200 epochs, batch = 256, λ = 10⁻⁴).
6. **Evaluation** — loss/accuracy curves, classification report, confusion matrices (train/validation/test) and weighted metrics.

**Test set results**

| Metric (weighted) | Value |
|---|---|
| Accuracy | 0.872 |
| Precision | 0.778 |
| Recall | 0.872 |
| F1-score | 0.819 |

Faults 2, 3 and 12 are recognized almost perfectly. **Fault 17, however, is not detected** and ends up confused with the `normal` class: with the available variables it is not linearly separable. This motivates non-linear models (neural networks) in the next assignments.

## 🚀 How to run

### Option 1 — Google Colab (recommended for Part 2)

Part 2 was written for **Google Colab**: it clones CSTRSIM, installs `fortranformat` and changes the working directory to `/content/CSTRSIM/python`.

1. Open [Google Colab](https://colab.research.google.com/) → *File* → *Open notebook* → *GitHub* tab.
2. Paste this repository's URL and choose the notebook.
3. Run the cells in order (*Runtime* → *Run all*).

### Option 2 — Local environment

Requirements: **Python 3.10+** (developed with 3.12).

```bash
git clone <this-repository-url>
cd ANN-2026-1

python -m venv venv
source venv/bin/activate        # Windows: venv\Scripts\activate
pip install -r requirements.txt

jupyter notebook
```
